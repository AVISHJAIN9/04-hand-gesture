# Frequently Asked Questions: MediaPipe Hand Gesture Video Player

### 1. What is MediaPipe Hand Gesture Video Player?
In-browser computer vision media player controller powered by Google MediaPipe gesture recognition.

### 2. What technology stack does it use?
Built with MediaPipe Hands, WebRTC Camera Stream, Vanilla JS / HTML5 Canvas.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/33-hand-gesture-cv/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
