# Gaps & Engineering Roadmap

## Identified Gaps & Upgrades
1. **Dynamic Lighting Compensation**: Implement automatic image contrast enhancement on incoming camera frames for dark kitchen environments.
2. **Custom Gesture Training**: Add in-browser Few-Shot transfer learning allowing users to record custom gesture bindings (e.g., wave left to rewind).
3. **PWA Offline Caching**: Package Wasm assets in a Progressive Web App service worker for 100% offline kitchen usage.
