# Technical Glossary

- **MediaPipe**: An open-source, cross-platform framework by Google for building applied machine learning pipelines.
- **WebAssembly (WASM)**: A binary instruction format for a stack-based virtual machine, enabling near-native code execution in web browsers.
- **WebGL**: A JavaScript API for rendering high-performance interactive 3D and 2D graphics within any compatible web browser without plugins.
- **3D Hand Landmarks**: A set of 21 three-dimensional coordinate points representing the skeletal joints of a human hand.
- **Debounce**: A programming practice used to ensure that time-consuming tasks do not fire so often, making them execute only once per specified duration.
