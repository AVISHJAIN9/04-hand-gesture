# Feature Inventory: Touchless Chef Gesture CV

## Overview of Core Features
- **F1: Client-Side WebAssembly Vision Pipeline & GPU Delegate**: High-speed edge neural network execution running a quantized float16 model directly on the client's graphics hardware.
- **F2: Real-Time Optical Frame Loop & Debounced Heuristic Action Dispatcher**: Synchronous 30fps optical video stream analysis with 1500ms time-decay debounce logic.
- **F3: Touchless Video Playback Engine & Kitchen Gesture Map**: Natural gesture bindings mapping Open Palm to Pause, Closed Fist to Play, and Thumbs Up to Skip.
- **F4: Privacy-First Zero-Server Camera Architecture & Live HUD Feedback**: Local frame processing guaranteeing zero biometric data leakage with interactive confidence overlays.
- **F5: Multi-Stream Recipe Player & Dynamic Video Ingestion**: Built-in library of culinary workshops with custom MP4 stream URL input.

## Say It Out Loud (Feature Summary)
"When presenting this project, I emphasize that it is an edge-computed ambient computing interface. Rather than treating computer vision as a remote backend service, I brought the neural network directly into the browser using WebAssembly and WebGL. This delivers zero-latency gesture recognition, protects user privacy, and functions completely offline once the initial model task is cached."
