# F5: Multi-Stream Recipe Player & Dynamic Video Ingestion

## 1. Description & User Workflow
`App.jsx` provides a curated catalog of recipe demonstration clips alongside an input field allowing users to paste any public MP4 or WebM video URL. The interface automatically adapts responsive video aspect ratios and overlays live gesture tracking HUD pills.

## 2. Say It Out Loud
"To make the application versatile beyond built-in demo clips, I built an ingestion pipeline supporting custom video streams. Users can choose from curated culinary clips or paste any public MP4 URL directly into the player. The interface provides a responsive, dark-mode viewport with a HUD badge indicating the currently recognized gesture and remaining debounce time, ensuring users always know exactly what the vision model is seeing."
